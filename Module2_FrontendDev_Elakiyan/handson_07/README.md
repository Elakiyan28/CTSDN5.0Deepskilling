# Hands-On 7 — Angular Student Portal

These are the source files only (Angular CLI project files like `angular.json`,
`tsconfig.json`, `package.json` are generated by the CLI, not hand-written).

## Setup

```bash
npm install -g @angular/cli
ng new student-portal-angular --routing --style css
cd student-portal-angular
```

Then copy the contents of `src/app/` and `src/styles.css` from this folder into
the generated project (overwrite `app.component.ts`, `app.component.html`,
`app.routes.ts`, `main.ts`, `styles.css`), and add the new folders:
`course-card/`, `course-list/`, `student-profile/`, `services/`.

```bash
ng serve
```

## What's implemented

- **Task 1**: `CourseCardComponent` (`@Input` + interpolation), `CourseListComponent`
  (`*ngFor`, two-way `[(ngModel)]` search via `FormsModule`, `*ngIf` empty state).
- **Task 2**: `CourseService` (`providedIn: 'root'`, injects `HttpClient`, returns an
  `Observable<Course[]>` from JSONPlaceholder), injected into `CourseListComponent`
  via constructor DI, with a `loading` flag driving `*ngIf`.
- **Task 3**: Routing (`/` → CourseList, `/profile` → StudentProfile) via
  `provideRouter` + `RouterLink`/`router-outlet`. `StudentProfileComponent` uses
  Reactive Forms (`FormGroup`/`FormControl`/`Validators`) with inline error
  messages and a submit button disabled until valid.
